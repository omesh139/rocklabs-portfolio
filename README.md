# RockLabs Portfolio

A responsive React + Vite portfolio for RockLabs.

## Run locally
1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed by Vite.

## Production build
Run `npm run build`. Vite outputs the static site to `dist/`.
Run `npm run preview` to preview the production build locally.

## Deploy to Vercel
- Import the project/repository into Vercel.
- Framework preset: Vite.
- Build command: `npm run build`.
- Output directory: `dist`.
- No environment variables are required for the current static portfolio.

## Before launch
- Confirm `hello@rocklabs.us` is an inbox you can receive mail at.
- Update the canonical/OG domain in `index.html` if the final domain is different.
- Add your real public profile URLs when ready.
- Replace portfolio summaries/statuses with final project details where needed.

## Stack
React, Vite, Lucide icons, CSS.
